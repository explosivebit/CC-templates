# agents/

Агенты Claude Code. Каждый агент — один `.md` файл с YAML-frontmatter.

---

## Шаблон `<agent-name>.md`

```markdown
---
name: <agent-name>
description: Запускается, когда <триггер>. Примеры: <короткий сценарий 1>; <короткий сценарий 2>.
tools: Read, Grep, Glob, Bash     # опционально: ограничить набор инструментов
model: sonnet                     # опционально: sonnet | opus | haiku
---

# <Название>

## Роль

Одно-два предложения: кем является агент и какую конкретную работу делает.

## Входные данные

- Что получает на вход (например: путь до файла, номер PR).

## Процесс

1. Шаг 1
2. Шаг 2

## Выход

Формат ответа, который агент возвращает в основной разговор.

## Границы

- Чего агент НЕ делает (например: не пишет код, только ревью).
```

---

## Правила

- **Имя файла** = `<name>.md`, `kebab-case`.
- **`description`** с примерами триггеров — это то, по чему Claude решает,
  вызвать агента или нет. Пиши ситуации, а не возможности.
- Ограничивай `tools` минимально достаточным набором — меньше инструментов
  = меньше шума, выше фокус.
- Агент ≠ скилл: агент **исполняется в изолированном подпроцессе** и
  возвращает summary. Скилл исполняется в основном разговоре.

## Установка

```bash
cp agents/<name>.md ~/.claude/agents/
# или
ln -s "$(pwd)/agents/<name>.md" ~/.claude/agents/<name>.md
```
