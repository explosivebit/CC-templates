# prompts/

Шаблоны разовых промптов. Не скиллы и не команды — просто «скопировать и
вставить» в чат, когда нужно.

Организация — **по темам** в подпапках:

```
prompts/
├── code-review/
├── planning/
├── refactoring/
├── debugging/
└── docs/
```

---

## Шаблон файла `<topic>/<name>.md`

```markdown
# <Название промпта>

**Когда использовать**: одна строка — в каком сценарии этот промпт уместен.

**Ожидаемый вход**: что нужно подставить (код, ссылку, описание задачи).

**Ожидаемый выход**: что Claude вернёт (список, план, рефактор, ответ).

---

## Промпт

```
<тело промпта — то, что копируется в чат>
```

## Заметки

- Нюансы, edge-cases, варианты.
```

---

## Правила

- **Имя файла** — `kebab-case`, суффикс по желанию (`.ru.md` если RU-специфика).
- Один файл = один промпт с одной целью. Варианты — отдельные файлы в той
  же папке с суффиксом (`code-review-strict.md`, `code-review-friendly.md`).
- Если промпт начинает жить собственной жизнью (растёт, дорабатывается, имеет
  шаги) — **перенеси в `commands/`** как slash-команду или в `skills/`.
- Держи контекст проекта **внутри промпта** в явных плейсхолдерах
  `<PROJECT_PATH>`, `<FILE>`, чтобы сразу видеть, что подставлять.
